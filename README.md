# Vision Metrics - Retail Analytics & Person Tracking

Профессиональная система интеллектуального видеонаблюдения для ритейла на базе нейросетей **YOLO** и трекеров **BoxMOT (HybridSort)**. Позволяет классифицировать роли (Сотрудник / Клиент), отслеживать время нахождения в зонах и формировать детальные JSON-отчеты для бизнес-аналитики.

---

## 🛠 Архитектура системы

Проект разделен на независимые модули по принципу Domain Driven Design:
- **`core/`**: Ядро системы (инференс YOLO, трекинг, классификация ролей, логгирование данных).
- **`ui/`**: Современный графический интерфейс на PyQt6.
- **`config/`**: Централизованные настройки (модели, пути, параметры трекера).
- **`utils/`**: Вспомогательные инструменты (визуализация, мониторинг ресурсов).

## 🚀 Быстрый старт

### 1. Подготовка окружения
Убедитесь, что у вас установлена Anaconda или Miniconda.
```bash
# Активация окружения (предполагается, что оно создано)
conda activate vision_metrics
```

### 2. Запуск графического интерфейса
Используется для настройки зон, мониторинга в реальном времени и отладки.
```bash
python main.py
```
**Ключевые фишки GUI:**
- **Max Power Mode 🚀**: Режим максимальной производительности (отключает видео, бросая все силы на обсчет данных).
- **JSON Inspector**: Просмотр данных по каждому кадру прямо в приложении.

### 3. Запуск через командную строку (CLI)
Используется для массовой фоновой обработки видео на серверах.
```bash
python cli.py --source ./data/videos/your_video.mp4 --device mps
```
*Параметры:*
- `--source`: Путь к видео или RTSP-потоку.
- `--weights`: Путь к модели YOLO (опционально).
- `--device`: Устройство расчета (`cpu`, `cuda`, `mps`).

## ⚠️ Решение проблем (Troubleshooting)

### Ошибка: Exit Code 247 (Out of Memory)
На устройствах с ограниченной памятью (например, Mac 8GB/16GB) тяжелые модели могут вызывать падение.
**Решение:**
1. Откройте `config/yolo.py`.
2. Замените `YOLO26M_SEG` на `YOLO26S_SEG` (модель Small более экономична).
3. Используйте режим **Max Power** в приложении.

### Ошибка: ModuleNotFoundError
Убедитесь, что вы запустили скрипт из активированного conda-окружения:
`conda activate vision_metrics`
